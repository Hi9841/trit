Speech runtime benchmark

Same model, different runtime

Each model here runs on every CPU runtime that supports it, so the runtime is the only difference. Trit, TDT's own engine, runs every model at each precision: auto (its default), int8, f16, and f32. For Whisper and Moonshine, Trit's default is beam search with 5 beams; every runtime that has beam search runs it with 5 beams too, and greedy rows of every runtime (Trit included) stay for comparison. The other runtimes are Photon, ONNX Runtime, sherpa-onnx, faster-whisper, whisper.cpp, Transformers, OpenAI Whisper, and llama.cpp. Same 456 English clips, same computer, same scorer.
